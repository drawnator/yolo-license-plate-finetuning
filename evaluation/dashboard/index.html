How the numbers are computed
  • Scores come from python -m evaluation.benchmark (same images and settings for every model: imgsz=640, Ultralytics validation defaults). Training-time validation scores are shown in the table only for reference; they used different data and are not comparable.
  • For the selected classes, each dataset's score is the mean over the selected classes it annotates; the overall score is the mean over the selected datasets. With all classes selected this equals the benchmark's overall/… value.
  • A model is only ranked when it can detect every selected class. Plate + face models (V1 to v5) appear when the selection is limited to plate and face.
  • Speed is the inference time per image on the GPU that ran the benchmark (RTX 4060 Ti), weighted by dataset size.
